# Ethics

KreyolBench is intended to improve Haitian Creole language technology for public-interest use. Risks include privacy leakage, domain skew, orthographic bias, overclaiming dialect coverage, and harmful use in surveillance or service denial.

## Mitigations

- PII detection and redaction before release.
- Explicit source and license metadata.
- Raw and normalized text preservation to avoid erasing variation.
- Error analysis by domain, spelling variation, code-switching, and formal/informal register.
- Clear out-of-scope use policy in dataset and model cards.
