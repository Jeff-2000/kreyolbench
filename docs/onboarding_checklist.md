# Collaborator Onboarding Checklist

Use this checklist for every collaborator who moves beyond casual public discussion.

## Before Access

- [ ] Intake form completed.
- [ ] Role selected.
- [ ] Access level selected.
- [ ] Conflict of interest reviewed.
- [ ] First task assigned.
- [ ] Project charter shared.
- [ ] Governance policy shared.
- [ ] Code of conduct shared.
- [ ] Data access policy shared.
- [ ] Authorship policy shared if research output is expected.

## First Task

Assign one small non-sensitive task:

- [ ] Document review.
- [ ] Small bug fix.
- [ ] Public sample annotation.
- [ ] Baseline reproduction.
- [ ] Literature summary.
- [ ] Source registry validation.

## Access Setup

- [ ] GitHub username recorded.
- [ ] Repository access granted only if needed.
- [ ] Private document access granted only if needed.
- [ ] Restricted data access denied by default.
- [ ] Communication channel added.
- [ ] Sprint board access added if needed.

## Expectations

- [ ] Contribution scope documented.
- [ ] Timeline documented.
- [ ] Expected credit discussed.
- [ ] Meeting cadence explained.
- [ ] Update format explained.
- [ ] Data rules explained.

## After First Contribution

- [ ] Contribution reviewed.
- [ ] Feedback provided.
- [ ] Access level confirmed or adjusted.
- [ ] Next task assigned.
- [ ] Contribution tracked for credit.
