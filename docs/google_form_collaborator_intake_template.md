# Google Form Template: KreyolBench Collaborator Intake

Use this as the official intake form for new collaborators before granting access beyond public GitHub issues and pull requests.

Do not ask people to upload IDs, signatures, passports, private datasets, API keys, or sensitive documents through this form. If a collaborator later needs a signed MOU, restricted data access, or institutional agreement, handle that separately through a controlled private process.

## Recommended Google Form Settings

- Collect email addresses: **On**
- Send responders a copy of their response: **On**
- Allow response editing: **On**
- Limit to 1 response: **Off**, unless all collaborators have Google accounts
- Presentation confirmation message:

```text
Thank you for your interest in KreyolBench. I will review your response and follow up with the appropriate next step. New collaborators normally begin with a small public or non-sensitive task before receiving broader access.
```

- Store responses in a linked Google Sheet.
- Restrict response spreadsheet access to the project lead and trusted coordination team only.

## Form Title

```text
KreyolBench Collaborator Intake Form
```

## Form Description

```text
KreyolBench is a Haitian Creole AI research project focused on public-interest NLP, speech, machine translation, LLM evaluation, statistical reliability, education, civic information access, and language technology infrastructure.

This form helps classify collaboration interests, expertise, expected contributions, access needs, and possible conflicts of interest. Completing this form does not automatically grant access to private documents, restricted data, authorship, or repository permissions.

New collaborators usually begin with a small non-sensitive task such as reviewing documentation, validating a source registry entry, running a public baseline, writing a literature summary, or contributing to a public GitHub issue.

Please do not submit private data, restricted corpora, API keys, passwords, signed documents, or sensitive personal information in this form.
```
