# KreyolBench Blueprint

KreyolBench is a Kreyol-first Haitian Creole benchmark suite for classification, NER, QA, retrieval, normalization, translation evaluation, code-switch detection, sentiment, summarization, and orthographic robustness.

## v0.1 Scope

The minimum viable benchmark includes topic/domain classification, named entity recognition, extractive QA, retrieval, normalization, code-switch detection, and translation evaluation metadata. It targets public-health, education, civic administration, disaster-response, and other public-interest domains.

## Release Roadmap

- `v0.1`: public scaffold, source registry, sample data, validation CLI, core metrics, baseline placeholders.
- `v0.2`: expanded annotations, sentiment, summarization, leaderboard submissions.
- `v1.0`: stable public and hidden tests, stronger baselines, publishable paper package.
- `v2`: document QA, OCR-heavy sources, dialect/region metadata, disaster temporal benchmark.

## Research Positioning

KreyolBench complements CreoleVal by going deeper on Haitian Creole, public-service domains, orthographic variation, code-switching, provenance, and reproducible evaluation. It must not claim complete dialect coverage or unrestricted openness of all Haitian Creole resources.
