# KreyolBench Blueprint

KreyolBench is a Kreyol-first research program and extensible benchmark ecosystem for Haitian Creole NLP and AI evaluation. It is not limited to the tasks implemented in the current text scaffold.

## v0.1 Scope

The controlled pilot proposes five task instances: multi-label topic classification, character-span NER, hybrid-query retrieval, orthographic normalization, and token-level code-switch identification. QA remains feasibility-only and translation is deferred. No task is yet included in a release.

## Release Roadmap

- `v0.1`: public scaffold, source registry, sample data, validation CLI, core metrics, baseline placeholders.
- `v0.2`: independently reviewed task specifications, one or more authorized annotation pilots, and preliminary reproducible baselines.
- `v1.0`: stable public and hidden tests, stronger baselines, publishable paper package.
- Later tracks may include new task instances, domains, speech, OCR, document, multimodal, robustness, and LLM evaluation after separate review.

## Research Positioning

KreyolBench intends to investigate Haitian Creole-specific linguistic variation, public-interest use cases, provenance, contamination, uncertainty, and benchmark reliability. Comparative positioning against CreoleVal or other resources requires a systematic evidence review. It must not claim complete coverage, unrestricted openness, priority, scale, or superiority without evidence.
