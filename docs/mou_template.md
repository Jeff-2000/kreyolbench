Restricted data access requires separate approval under `DATA_ACCESS_POLICY.md`.

## Confidentiality

The collaborator agrees not to share private drafts, restricted data, unpublished results, credentials, partner information, or internal decisions without permission.

## Data Use

The collaborator agrees to:

- Use data only for the approved project scope.
- Not redistribute data unless explicitly approved.
- Follow source license and consent requirements.
- Report privacy, license, or security concerns immediately.

## Authorship and Credit

Expected credit path:

- Authorship considered if contribution is substantial and meets `AUTHORSHIP.md`.
- Acknowledgement for smaller contributions.
- No guaranteed authorship unless explicitly agreed in writing.

Authorship order will be discussed before submission.

## Publication

Manuscripts, preprints, talks, public posts, and grant submissions using project data, branding, or results require project-lead review before public release.

## Exit

If the collaborator leaves the project:

- Access will be removed when no longer needed.
- Private or restricted data must be deleted or returned where appropriate.
- Completed contributions remain credited.
- Unfinished tasks should be handed off with notes.
