# Error Analysis

## Purpose

Define required qualitative and quantitative error analysis dimensions.

## Status

Current status: SUBMITTED_TO_REVIEW

Owner: Codex

Requires expert validation: Yes

## Dimensions

Analyze errors by:

- domain
- source family
- register
- formal vs informal Kreyol
- orthographic variation
- code-switching
- entity type
- answerability
- document length
- query type
- rare labels
- temporal source period where available

## Haitian Creole-Specific Considerations

- Do not treat French-looking tokens as automatically French.
- Account for Haitian place names, institutions, and public-sector terminology.
- Preserve raw spelling variation for analysis.
- Review code-switch labels with language experts.

## Publication Artifacts

Candidate artifacts:

- confusion matrices
- per-domain metric table
- common NER boundary errors
- normalization edit-type table
- retrieval failure examples
- QA unanswerable error table
