# Submission Policy

## Purpose

Define requirements for model submissions.

## Status

Current status: SUBMITTED_TO_REVIEW

Owner: Codex

Requires expert validation: Yes

## Required Fields

- submission ID
- model name
- task
- dataset version
- split version
- training setting
- primary metric
- metric value
- code URL where public
- model URL where public
- compute budget
- data used
- date submitted
- verification status

## Verification States

- unverified
- metadata complete
- rerun by maintainer
- accepted official
- rejected
- deprecated

## Rejection Reasons

- incomplete metadata
- incompatible training setting
- test contamination
- missing code or reproducibility details
- license violation
- suspicious result requiring audit
