# Leaderboard Reproducibility Requirements

## Purpose

Define reproducibility requirements for leaderboard entries.

## Status

Current status: SUBMITTED_TO_REVIEW

Owner: Codex

Requires expert validation: Yes

## Minimum Requirements

- dataset version
- model identifier and revision
- training setting
- code or method description
- data declaration
- compute declaration
- seed where applicable
- evaluation config
- result JSON

## Higher-Confidence Requirements

- public code
- environment file or lockfile
- rerunnable command
- stored predictions
- confidence intervals
- maintainer rerun

## Policy

Leaderboard entries may be displayed as unverified, but only verified entries should be used for official claims.
